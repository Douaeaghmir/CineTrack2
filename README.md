## 📌 À propos du projet

**CINATRACK** est une application web de découverte et de consultation de films. Elle offre une interface intuitive permettant aux utilisateurs d'explorer un catalogue de films, de rechercher des titres spécifiques, de filtrer les résultats et de sauvegarder leurs films préférés.

Ce projet a été réalisé dans le cadre de notre formation en développement web afin de mettre en pratique les concepts fondamentaux de JavaScript et de développer une application interactive utilisant une API externe.

## ✨ Fonctionnalités principales

- 🎥 **Affichage des films :** Présentation des films sous forme de cartes avec leurs informations.
- 🔎 **Recherche dynamique :** Recherche de films selon leur titre.
- 🎭 **Filtrage :** Filtrage des films selon différents critères.
- ❤️ **Favoris :** Ajout et suppression de films dans une liste de favoris.
- 💾 **Persistance des données :** Sauvegarde des favoris grâce à localStorage.
- 🌐 **API :** Récupération dynamique des données cinématographiques.
- 📱 **Interface utilisateur :** Interface claire et adaptée à une navigation intuitive.

## 🛠️ Technologies utilisées

| Technologie | Utilisation |

# 🎬 CineTrack2

## 📖 Présentation du projet

CineTrack2 est une application web de gestion de films qui permet aux utilisateurs de découvrir, consulter et gérer une collection de films. L'application propose également un système de commentaires permettant aux utilisateurs de partager leurs avis.

## ✨ Fonctionnalités principales

### 🎥 Interface utilisateur
- Afficher une liste de films.
- Consulter les détails de chaque film.
- Rechercher et filtrer les films.
- Ajouter des commentaires aux films.
- Afficher les commentaires associés à chaque film.

### 🔐 Tableau de bord administrateur
- Afficher tous les films dans un tableau.
- Ajouter de nouveaux films.
- Modifier les informations des films existants.
- Gérer les données des films à travers une API.

### 💬 Gestion des commentaires
- Récupérer les commentaires depuis l'API.
- Ajouter de nouveaux commentaires.
- Afficher les commentaires dans une fenêtre modale.

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- Fetch API
- MockAPI
- Git et GitHub

- Organiser le code avec les modules JavaScript.
- Manipuler le DOM et gérer les événements.
